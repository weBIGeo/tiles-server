Background processes

Server that processes and serves geo tiles from various sources (e.g. weather stations) for weather, snow, and other map overlays.

This is currently a skeleton — it only exposes a status endpoint. Built for the weBIGeo web-based geographic visualization project. You can see weBIGeo in action at webigeo.alpinemaps.org.

GET /v1/status · /status

Returns the server version and current status.

{
  "version": "0.1",
  "status": "idle"
}
GET /v1/processes

Snapshot of currently running (and recently finished) background processes, e.g. tile generation jobs. Rendered as the progress bars above. A process disappears from this list a short while after it finishes.

[{
  "key": "debug_ortho",
  "label": "Debug ortho tiles",
  "state": "running",
  "current": 4200,
  "total": 9938,
  "message": "z=17"
}]
GET /v1/debug-ortho/status

Readiness of the debug ortho tile dataset (see below). generating while it's being downloaded/built in the background, ready once tiles can be served, error if generation failed.

{ "status": "ready" }
GET /v1/debug-ortho/<z>/<y>/<x>.jpeg

Self-generating debug dataset: real basemap.at orthofoto tiles (zoom 0-20) for Vienna's 1st district, each labeled with its own z/x/y, plus artificial red-tinted zoom-21 tiles over Stephansplatz (synthesized from the zoom-20 tiles). Path order matches basemap.at's own WMTS layout (z/y/x). Returns image/jpeg on success, 503 while the dataset is still generating, 404 for any tile outside the covered area/zoom range.

COSMOS snow depth — generate a day

Snow depth tiles (exolabs/COSMOS, cropped to Lower Austria) are generated on demand per day rather than on server startup. Pick a date and generate it here; progress shows up in Background processes above, and the result appears as a selectable layer on the map once ready.

GET /v1/cosmos-snow/dates

Lists every date that has been generated or is currently generating.

[{ "date": "2026-01-01", "status": "ready" }]
POST /v1/cosmos-snow/<date>/generate

Starts background generation for date (YYYY-MM-DD) if it isn't already ready or generating; otherwise a no-op that just returns the current status. 400 for a malformed or future date.

{ "date": "2026-01-02", "status": "generating" }
GET /v1/cosmos-snow/<date>/status

Readiness of one day's snow-depth dataset: generating, ready, error, or unknown if that date was never requested.

{ "status": "ready" }
GET /v1/cosmos-snow/<date>/<z>/<x>/<y>.png

Snow depth in centimeters, cropped to Lower Austria, zoom 0-13 (source resolution is 20m/px, z13 is the highest zoom that reflects real detail rather than upsampling). Value encoding: depth_cm = R*256 + G, blue unused, alpha 0 (transparent) wherever depth is 0 or the source pixel is nodata. Returns image/png on success, 503 while that date is still generating, 404 for any tile outside the covered area/zoom range.
